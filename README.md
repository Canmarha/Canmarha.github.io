## 📝 Customization

To customize this site:

1. **Update home page content** — Edit `index.html` hero section and about details
2. **Modify colors** — Change CSS variables in `styles.css`
3. **Add project pages** — Create new HTML files in `projects/`
4. **Update links** — Keep GitHub repository URLs current

## 🔧 Build & Deploy

This site is automatically deployed via GitHub Pages on every commit to `main`.

```bash
# Clone this repository
git clone https://github.com/Canmarha/Canmarha.github.io.git
cd Canmarha.github.io

# Make local edits
# Commit and push to deploy
git add .
git commit -m "Update portfolio content"
git push origin main
```
