Visual Studio Code

Custom VS Code fork with advanced automation and AI integration

Overview

A personalized fork of Visual Studio Code optimized for full-stack automation engineering and AI systems development. This project extends VS Code with:

  • Advanced agent integration for AI-assisted development
  • Cross-platform development environment configuration
  • Custom automation and scripting capabilities
  • Enhanced developer experience for DevOps workflows
  • Integrated tooling for cloud and container orchestration

Key Features

🤖 AI Agent Integration

Seamless integration with GitHub Copilot and AI-powered coding assistants.

🛠️ Advanced Tooling

Pre-configured for DevOps, automation, and infrastructure-as-code workflows.

🌍 Cross-Platform Ready

Optimized for Windows, WSL, Linux, macOS, and container environments.

⚡ Performance Tuned

Custom optimizations for large codebases and remote development scenarios.

Build & Development

clone: git clone https://github.com/Canmarha/vscode.git
install: npm install
build: npm run build
test: npm test
launch: npm start

Requirements: Node.js 18+, npm 8+, Python 3.8+ (for build scripts)

Customizations

  • Agent configuration files in .agents/
  • Custom dev container setup in .devcontainer/
  • Extended marketplace extensions
  • Custom keybindings for automation workflows
  • Pre-configured terminals and tasks

Tech Stack

TypeScript • Node.js • Electron • VSCode API • GitHub APIs
